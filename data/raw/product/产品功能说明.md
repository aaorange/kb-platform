# 知识库平台产品功能说明

文档编号：PD-2026-001 | 版本：v1.0 | 发布日期：2026-08-01 | 密级：项目负责人专属

## 一、产品定位

企业知识库管理平台，面向中大型企业内部知识问答场景，核心能力：多源文档导入、四维权限管控、AI 鉴权检索问答、知识自动沉淀。

## 二、核心模块

**知识维护与导入中心**：支持 PDF、Markdown、Word、TXT 单篇上传和批量拖拽导入，自动完成文本提取、语义分块、向量化入库。知识单元支持启用、归档生命周期管理。

**组织架构与权限体系**：部门树、角色、用户三级组织模型。功能权限控制菜单和按钮可见性；数据权限分全局、部门、角色、个人四个维度，OR 逻辑判定。

**AI 鉴权问答**：用户提问后先匹配 FAQ 缓存，未命中走混合检索（向量 + 关键词），检索结果经过权限过滤后拼接 Prompt 流式生成，回答附带引用溯源。

**知识沉淀运营**：定时聚类历史问答生成候选 FAQ，管理员审核发布后写入缓存加速；未命中提问进入知识缺口池，驱动知识补充。

## 三、技术栈要点

后端 FastAPI + PostgreSQL + Milvus + Redis + Celery。前端 Vue3 + Element Plus。大模型走 OpenAI 兼容 API，Embedding 使用 bge 系列。

## 四、本阶段开发计划

数据工程（本周）：文档集、分块向量化 pipeline、评估集。
后端开发（2-3 周）：认证、组织、知识导入、鉴权引擎、问答链路。
前端开发（1-2 周）：五大页面。
联调部署（1 周）：端到端场景验证 + Docker 部署。
